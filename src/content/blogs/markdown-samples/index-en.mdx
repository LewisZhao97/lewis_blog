## Block Elements

### Paragraphs and Line Breaks

#### Paragraphs

HTML Tag: `<p>`

One or more blank lines.

```text
This will be
inline.

This is second paragraph.
```

---

This will be
inline.

This is second paragraph.

---

#### Line Breaks

HTML Tag: `<br />`

End a line with **two or more spaces**.

```text
This will be not
inline.
```

---

### Headers

#### Setext

```text
This is an H1
=============

This is an H2
-------------
```

---

---

```text
# This is an H1
## This is an H2

```
